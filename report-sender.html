⚠️ EmailJS Template — one-time setup
1 Go to emailjs.com → Login → Email Templates
2 Open the template whose ID matches the Template ID above
3 Write the Subject and Content however you like — the report goes out as a PDF attachment, so the body is just your message
4 Set To Email = {{to_email}}
5 To control the sender name from this app, set From Name = {{from_name}}
6 Click Save

📧 Template Variables the app sends

{{to_email}} — Restaurant email
{{to_name}} — Restaurant name
{{week_label}} — Week period
{{balance}} — Net payout
{{reply_to}} — Your email
{{from_name}} — Sender name
The report itself is attached as a PDF — there is no HTML body variable.

🌐 Connect Your Domain

Step 2 — Add Gmail with your domain
Email Services → Add Service → Gmail → connect [email protected]

Step 3 — Update Service ID
Copy the new Service ID → paste it in ⚙ Email Settings in this app.

Alternative — Use Google Workspace
If you have Google Workspace with branchef.ca, connect that Gmail account in EmailJS — emails will send from [email protected] directly.
